# 02 · TROPICA — путешествия в тропики

Концепт сайта авторских путешествий для портфолио на Kwork. Демонстрационный проект: компания, цены и маршруты вымышлены, форма работает в демо-режиме (данные не отправляются).

## Страницы

| Файл | Страница | Что показывает заказчику |
|---|---|---|
| `index.html` | Главная | Полноэкранное видео-hero с фото-постером, популярные направления, подход, этапы работы |
| `directions.html` | Направления | Рабочие фильтры по типу отдыха и сезону + таблица сезонности по месяцам |
| `tour.html` | Путешествие (Мальдивы) | Программа по дням, липкая карточка цены, галерея с лайтбоксом, размещение, «включено / не включено» |
| `about.html` | О проекте и контакты | Подход и принципы, FAQ-аккордеон, форма заявки с валидацией |

## Дизайн-система

- **Палитра:** глубокий океан `#07272f`, бирюза `#0e8388 / #19b8b2`, солнечный акцент `#ffb340`, белый фон
- **Шрифты:** Manrope (интерфейс и заголовки) + Playfair Display Italic (акцентные слова)
- **Компоненты:** единые кнопки, карточки, чипы-фильтры, аккордеон, формы — всё в `styles.css`

## Видео на главной — как устроено

1. Сразу видна **фото-заставка** (постер) — экран никогда не пустой.
2. Видео **без звука**, автозапуск в фоне (`muted + playsinline`).
3. При `prefers-reduced-motion` или ошибке загрузки видео **отключается**, остаётся статичное фото.
4. Ролик — Pexels (бесплатная лицензия, коммерческое использование разрешено). Заменить: поменять `<source>` в `index.html` или положить свой файл и указать путь к нему.

## Техника

- Чистый HTML/CSS/JS, без сборки — открывается из папки и деплоится куда угодно
- Адаптив: 1240 / 1024 / 820 / 560 px, мобильное меню
- Доступность: семантика, `aria-expanded`, фокусы, поддержка `prefers-reduced-motion`
- **Видео-обложка:** плейлист из 4 роликов по кругу — `assets/video/hero-1.mp4` → `hero-2.mp4` → `hero-3.mp4` → `hero-4.mp4` → снова `hero-1`. Без звука, с фото-постером до загрузки. Список задаётся в `app.js` (константа `HERO_CLIPS`). Если файла нет — пропускается, при отсутствии всех роликов остаётся постер.
- **Полностью автономен:** фото (`assets/img/`), видео (`assets/video/`) и шрифты (`assets/fonts/`, кириллица+латиница) лежат внутри проекта — сайт работает без интернета и не зависит от доступности CDN

## Деплой на Vercel

1. Создать репозиторий и залить папку проекта (или весь `kwork-portfolio`).
2. Vercel → New Project → Import.
3. Framework Preset: **Other**, Root Directory: `02-tropica-travel` (если деплоится отдельно).
4. Deploy — готово, билд не требуется.

## Что подключить в «боевой» версии

- Отправку формы (Telegram-бот / почта / CRM) вместо демо-валидации в `app.js`
- Реальные мессенджеры в контактах, метрику (Яндекс.Метрика), favicon-пакет
