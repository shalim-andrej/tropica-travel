**TROPICA — путешествия, в которые влюбляются**

Многостраничный сайт туристического направления: тёплая премиальная эстетика, видео-обложка на главной, живые фильтры и заявка на подбор тура.

## Страницы (4)
- `index.html` — главная: видео-обложка, направления, преимущества
- `directions.html` — каталог направлений: фильтры по типу отдыха и сезону
- `tour.html` — страница путешествия: программа по дням, галерея, форма заявки
- `about.html` — о бренде: история и философия

## Функционал (чистый JS, без зависимостей)
- Фильтры каталога по типу отдыха и сезону
- Программа тура по дням с галереей
- Форма заявки на подбор направления
- Адаптив 360–1920, плавные анимации

## Стек
HTML, CSS, JavaScript — статические файлы без сборки.

## Запуск
Открыть `index.html` двойным кликом — сайт полностью офлайн.
